🔄 USER FLOW

1. PRODUCT DISCOVERY
   Users browse products on /products page
   Sees: Product card with image, name, price, rating

   Sees: Full product page with all details

3. IMAGE EXPLORATION
   User views images in gallery
   Can: Click to zoom, use arrow keys, click thumbnails
   Sees: Image counter, smooth animations

4. INFORMATION REVIEW
   User reads description and specifications
   Can: Expand/collapse spec sections
   Sees: Organized information with icons

5. DECISION MAKING
   User checks: Price, stock, rating, reviews
   User sees: Trust badges, shipping info, returns policy

6. ACTION
   User chooses quantity
   User clicks: "Add to Cart" or "Buy Now"
   Result: Product added to cart or redirects to checkout

7. DISCOVERY
   User scrolls to bottom
   Sees: Related products in category
   Can: Click to view similar products

🛠️ TECHNICAL DETAILS
───────────────────────────────────────────────────────────────────────────────

Route Configuration (App.jsx):
  <Route path="products/:id" element={<ProductDetail />} />

API Endpoints Used:
  GET /api/products/:id              → Fetch product details
  GET /api/products?category=...     → Fetch related products

Data Structure (MongoDB):
  {
    _id: ObjectId,
    title: string,
    description: string | JSON array,
    category: string,
    brand: string,
    price_minor: number (cents),
    stock: number,
    images: [string],
    specifications: string | JSON,
    ...
  }

Context Integration:
  useCart()      → addToCart(), updateCartItem()
  useUser()      → isAuthenticated, user data
  useWishlist()  → addToWishlist(), removeFromWishlist()
  useToast()     → Show success/error messages

Utilities:
  formatINR()         → Format price to rupees
  calculateDiscount() → Calculate discount percentage

Animations:
  Framer Motion used throughout for:
  - Page transitions
  - Component entrance animations
  - Hover effects
  - Expand/collapse animations
  - Carousel smooth scrolling
