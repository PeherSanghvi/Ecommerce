                        QUICK START GUIDE
═════════════════════════════════════════════════════════════════════════════

To use the new Product Details page:

1. User clicks any product card on /products page
2. Browser navigates to /products/:id (MongoDB ObjectId)
3. ProductDetail.jsx loads and fetches product data
4. Components render:
   - ImageGallery displays images with zoom
   - Product details show price, rating, etc.
   - SpecificationsList shows specs in tabs
   - RelatedProducts carousel at bottom
5. User can:
   - Zoom images, navigate with arrows/thumbnails
   - Select quantity
   - Add to cart
   - Buy now
   - Add to wishlist
   - View specifications
   - See related products
